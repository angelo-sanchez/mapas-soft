Agregar opciones a tippecanoe. {{ panel.expanded ? "help" : "help_outline" }}

-z, --maximum-zoom: Establece el nivel máximo de zoom de los mosaicos generados.
Ejemplo: -z 14

-Z, --minimum-zoom: Establece el nivel mínimo de zoom de los mosaicos generados.
Ejemplo: -Z 6

--coalesce: Combina varias características en una sola si tienen el mismo valor de atributos y forman un polígono adyacente. Esto reduce el tamaño de los archivos.

--detect-shared-borders: Detecta y elimina bordes compartidos entre polígonos adyacentes para evitar duplicación de geometrías.

--extend-zooms-if-still-dropping: Permite que los niveles de zoom se extiendan si hay características que todavía se están descartando. Útil para preservar detalles en niveles altos.

-P, --parallel: Permite usar múltiples hilos para leer diferentes partes de un archivo GeoJSON al mismo tiempo, lo que mejora el rendimiento en archivos grandes
